## 🌌 故事簡介 (Synopsis)

這是一本結合**賽博龐克（Cyberpunk）、未來科幻與生態警世寓言**的台語原創繪本。

故事發生在科技極度發達、人類都市高度機械化的未來世界。然而，地球上的自然林木已枯竭殆盡，城市失去了微風與清新的氣息，人類甚至必須隨身背負或仰賴人工樹苗所製造的氧氣才能維生與呼吸。

在這樣的世界裡，主角在沉睡中做了一個不可思議的夢。夢境中，他踏上了一條神秘而悠遠的尋樹之路，目標是尋找傳說中守護整片大地生機的大自然長老——「**樹王公**」。在長途的「**搜揣（尋找）**」過程中，主角穿越了荒蕪與科技的邊界，重新看見了土地的脈動、樹根緊抓泥土的力量，以及生命呼吸的源頭，深刻體會到：

> **「沒有大自然，就沒有新鮮空氣；守護老樹，就是守護我們自己的呼吸。」**

## 🌿 從繪本到 WebGIS：將夢境化為現實行動

在繪本《CHHIAU-CHHŌE樹王公》中，孩子在睡夢中尋找大樹；而在現實生活中，**臺灣受保護樹木與珍貴老樹 WebGIS 全國地理資訊系統** 正是這本繪本在真實世界中的實踐與延伸！

- **全臺老樹大搜揣**：整合農業部林業試驗所與全臺 22 縣市政府官方權責普查清冊。
- **11,428 筆老樹點位**：將超過一萬棵被列管保護的珍貴老樹、百年名木與樹王公，標註在精確的地理空間座標上。
- **走出家門親炙自然**：讓讀者與公民在讀完繪本後，打開手機地圖，就能在自己生活的鄉鎮與城市角落，找到真實陪伴在我們身邊的「樹王公」，親身走訪、感受大自然長老的宏偉與生命力。
